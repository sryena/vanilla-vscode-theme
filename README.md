# Vainilla

Tema claro para VS Code: fondo amarillo vainilla (#F9E9AF), zonas oscuras en vainilla grisáceo, texto café con leche y
acentos pastel (menta, cereza, lavanda, celeste, melocotón, mostaza y rosa),
todos con contraste legible sobre el fondo.

- `themes/vainilla-color-theme.json`: el tema.
- `paleta.html`: guía visual de qué color es cada cosa.
- `muestras/`: archivos para ver el tema en HTML, CSS, Python, Markdown y JSON.

## Versiones

- **0.4.1** (2026-10-20): los colores de Git, errores, avisos y coincidencias de búsqueda de la barra
  lateral, un tono más oscuros para llegar a 4,5:1 sobre el gris y la selección (antes, 3,9-4,2:1; lo
  detectó impeccable). Los colores del código no cambian.
