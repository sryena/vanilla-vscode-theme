Dónde probar cada cosa

ArchivoQué enseña
muestra.pyPython: palabras clave, funciones, clases, decoradores, números, textos. Además tiene cambios sin commitear: verás las rayas menta, cereza y melocotón en el margen
muestra.htmlEtiquetas, atributos, entidades y JavaScript dentro de HTML
muestra.cssSelectores de etiqueta, clase, id y pseudoclase; propiedades y valores
muestra.mdMarkdown: títulos, listas, enlaces, citas y código
muestra.jsonClaves, textos, números y true/null
Control de código fuente (Ctrl+Shift+G)Pulsa sobre muestra.py: vista de cambios con fondos menta y cereza
Terminal (Ctrl+ñ)Colores de la terminal, por ejemplo con git status o ls --color
